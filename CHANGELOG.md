# Changelog

All notable changes to Lean are documented here. Lean is currently in
**alpha**: expect rough edges (see `README.md` Known limitations) and
update often — releases arrive through the built-in updater.

## [0.1.0] - 2026-09-20

First public alpha.

### Added

- Horizontal tabs with keyboard switching, previews, and reopen-closed-tab
- Omnibar search, URL entry, history, and open-tab matching
- Light, dark, and system themes with separate UI and webpage fonts
- Configurable page scrollbars and native scrolling
- WebKit content blocking (on by default)
- Download manager with live progress
- Top bar and collapsible sidebar layouts with a customizable toolbar
- Custom keyboard shortcuts
- Session restore and capped local history
- Signed in-app updates via Sparkle, served from GitHub releases
